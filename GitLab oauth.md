# GitLab oauth

## 驗證方式

gitlab 有很多的 **token** 

:star: 使用範例：
### oauth
```
git clone https://oauth2:${Personal Access Tokens}@gitlab.com/username/myrepo.git
```
### 用戶名與密碼
```
git clone https://${username}:${password}@gitlab.com/username/myrepo.git
```
